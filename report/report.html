1. Introduction

This report explains how a simple multi-section website for the Department of Computer Science and Engineering was created using only HTML (with a small internal style sheet for colours). The page contains six sections — About, Programmes, Faculty, Facilities, Enquiry and Contact — which are reached through a navigation bar at the top. The page was written in VS Code and tested in Google Chrome.

2. HTML Document Structure

Every HTML page follows a fixed skeleton. The skeleton used for the department page is shown below.

  • <!DOCTYPE html> – tells the browser that the document uses HTML5, so it renders in standards mode.
  • <html> – the root element that encloses the whole page; lang="en" sets the language.
  • <head> – holds information about the page (charset, title, styles) which is not shown in the body.
  • <title> – text shown on the browser tab and used by search engines and bookmarks.
  • <body> – contains everything the user actually sees: headings, text, images, tables and forms.

3. Headings, Paragraphs and Text Formatting

HTML provides six heading levels, <h1> (most important) to <h6>. The department name is an <h1>, each section title is an <h2> and sub-titles are <h3>. Text is written inside <p> paragraphs. Formatting tags used are <strong>/<b> (bold), <em> (italic emphasis), <mark> (highlight) and <br> (line break).

4. Lists

Lists group related items. An ordered list <ol> numbers its items automatically, while an unordered list <ul> uses bullets. Each item is written inside <li>. The subjects are shown as an ordered list and the facilities as an unordered list.

5. Hyperlinks

The anchor tag <a> creates links. The href attribute gives the destination. Three kinds of links are used: internal links (href="#faculty") in the navigation bar that jump to a section with that id, external links to the college website and other sites (opened in a new tab with target="_blank"), and an e-mail link using mailto:.

6. Images

Images are inserted with the empty tag <img>. The src attribute gives the path of the image file, alt gives alternate text that is read by screen readers and shown if the image fails to load, and width/height set its size in pixels. The department logo (images/logo.svg) is placed in the header, as seen in Figure 1.

7. Tables

A table is created with <table>. Each row is a <tr>; header cells use <th> (bold and centred by default) and data cells use <td>. Borders were added using CSS border and border-collapse.

8. Forms

Forms collect input from the user. The <form> tag has an action (where data is sent) and a method (get/post). <label> describes each field and is linked to it by the for attribute. Different type values give built-in validation: text, email (checks for @) and tel. A drop-down list is made with <select> and <option>, and type="submit" creates the submit button. The required attribute stops the form from being sent when a field is empty.

9. Semantic HTML

Semantic elements describe the meaning of their content instead of just its appearance. They make the code easier to read and help search engines and screen readers understand the page. The following were used:

ElementPurposeUse in this website
<header>Introductory content of a pageLogo and department name
<nav>Block of navigation linksLinks to all six sections
<main>Main, unique content (one per page)Wraps all the sections
<section>Thematic group of content with a headingAbout, Programmes, Faculty, etc.
<footer>Closing information of a pageCopyright and “Back to top” link

10. Conclusion

Using basic HTML tags a complete, readable department website was built. Structure tags gave the page its skeleton, semantic tags organised it into meaningful parts, and lists, tables, links, images and forms presented the department’s information. The source code has been uploaded to GitHub.
